Claude Sonnet 5.5 は API 単価を上げずに速度30%向上とツール呼び出し削減でタスク単位コストを最大30%下げ、分類特化モデル「Jev」は意思決定呼び出しを生成LLMの数十〜数百分の一に圧縮した。トークン単価から「ジョブ完了コスト」へ評価軸が移り、ミドルティアの実力がフラッグシップに迫ることで、エージェント運用のユニットエコノミーが塗り替わりつつある。

**3. エージェントの商用化が「行動」と「取引」の段階へ**
Meta が Enterprise Platform でMuseスタックの法人販売に乗り出し、Shopify はチェックアウト（購入完了）までをエージェントに開放、Instinct は100億ドル評価の資金調達で行動代行市場を裏付けた。Amazon がエージェントをブロックする一方でオープン標準（UCP/WebMCP）を推す陣営が固まりつつあり、エージェントコマースの標準争いが始まった。

**4. 推論効率と「効率=計算資源」の新常識**
OpenAI の Jalapeño ASIC が700WでGB300を上回る性能を実証し、Synopsys の Autopilot はチップ設計自体のAI自動化へ、Schneider の WCDU は電力・冷却の効率化へと、インフラの各レイヤーで効率が共通言語になった。Disaggregated Quantization のような推論最適化研究も、電力制約下でのAI成長を支える基盤技術として重要性を増している。

**5. 物理AIと基盤モデル企業を巡る資金・M&Aの集中**
AMD による World Labs の82億ドル買収は、GPUベンダーが空間インテリジェンス（物理AI）のエコシステムを直接取り込む前例のない動きだ。Instinct（100億ドル）と Modal（157.5億ドル）の調達と合わせ、アプリ・インフラ・モデルの全レイヤーに資金が集中しており、AI経済の規模拡大と過熱が同時に進んでいる。
