| 重要度 | ⭐⭐⭐ |

**概要**: Meta AIとイリノイ大学アーバナ・シャンペーン校の研究者が、EvoHarness-RLフレームワークを発表。この技術により、80億パラメータ（8B）の小型AIモデルが、Claude Opus 4.5のような大型フロンティアモデルと同等の性能を達成することに成功。長時間にわたる複雑なワークフローにおいて、AIエージェントの効率性を最適化する革新的なアプローチ。

**詳細ポイント**:
- EvoHarness-RLを使用したQwen3-8BモデルがALFWorldベンチマークで96.9%の成功率を達成（ベースラインReActから49.0ポイント向上）
- Claude Opus 4.5（96.4%）の性能に匹敵し、GPT-4.1とGPT-5にBPEプロンプトタイムハーネスを適用すると成功率が22.1ポイントと25.7ポイントそれぞれ向上
- 「ハーネス・アニーリング」と「ハーネス・エボリューション」という2つの重要な挙動を発見 - AIが訓練を通じてツール使用を最適化し、状況の複雑さに応じて戦略を動的に適応

**なぜ重要か**: この研究は、企業がエージェントワークフローのパフォーマンスを犠牲にすることなく計算コストを大幅に削減できることを示している。小型モデルがフロンティアモデルと同等のタスクを実行できれば、AIエージェントの導入コストを劇的に下げることができ、より広範囲の企業利用が可能になる。

**関連キーワード**: EvoHarness-RL, AIエージェントワークフロー, コスト効率化, 強化学習, BPEフレームワーク

| 項目 | 内容 |
|------|------|
| ソース | [The Verge](https://www.theverge.com/ai-artificial-intelligence/986176/data-center-pollution-epa-rule-change-air-permit) |
| 公開日 | 2026-08-28 |
| 重要度 | ⭐⭐⭐ |

**概要**: トランプ政権が連邦の大気汚染規則を廃止しようとしている。この変更により、データセンター開発者が公共の監視を回避できるようになる可能性がある。EPAは1970年代から存在する「新規ソース審査(New Source Review)」プロセスの連邦レベルでの公告とコメントの機会を廃止し、その負担を州に委ねようとしている。

**詳細ポイント**:
- EPAは「マイナー」汚染源の連邦レベルでの公共参加要件を廃止する計画。これにより、州や地方の大気当局が新しい汚染源について公衆に通知するかどうかを決定することになる。
- 環境団体は「マイナー」のラベルは誤称であり、このプロセスは隣人に重大な影響を与える可能性のあるプロジェクトをカバーしていると主張。
- xAIのColossus 1データセンター（テネシー州）が2025年にマイナーソース許可を申請し、数千件のコメントが寄せられた事例がある。NAACPとSELCは、無許可のガスタービンを設置したとしてxAIを訴えると脅した。

**なぜ重要か**: このニュースはAI業界にとって重要な環境規制の変更を示している。生成AIの急速な普及に伴い、データセンターの建設が急増しているが、環境影響への懸念も高まっている。公共の監視を制限することで、データセンター開発者が規制を回避しやすくなり、環境保護団体との対立が激化する可能性がある。

**関連キーワード**: 環境規制, データセンター, 生成AI, 大気汚染, 公共参加

### 2. 裁判所、トランプ政権によるAnthropicのブラックリスト登録は違法と判断

| 項目 | 内容 |
|------|------|
| ソース | [The Verge](https://www.theverge.com/ai-artificial-intelligence/985947/anthropic-supply-chain-risk-lawsuit-judge-ruling) |
| 公開日 | 2026-08-28 |
| 重要度 | ⭐⭐⭐ |

**概要**: カリフォルニア州連邦地方裁判所のRita F. Lin判事は、トランプ政権によるAnthropicのブラックリスト登録が憲法修正第1条に違反する違法な報復であると判断した。この決定は、AIラボとトランプ政権との数ヶ月にわたる法的闘争の結果である。

**詳細ポイント**:
- 訴訟は3月に提起され、トランプ政権がAnthropicを「サプライチェーン・リスク」と指定したのは、同社がAI技術の軍事利用に関する「レッドライン」を設定したことへの違法な報復であると主張。
- トランプ政権は軍とのAIラボの契約を再交渉し、ペンタゴンがAIを「あらゆる法的用途」で使用できるように拡大しようとした。多くのAIラボがこれに署名したが、Anthropicは米国人の大量監視や致命的な自律型兵器の使用を拒否した。
- 判事は、ペンタゴンの記録がAnthropicをサプライチェーン・リスクと指定したのは「報道を通じた敵対的な態度」によるものであり、「公共の監視を政府の契約立場にもたらすことへの罰としてAnthropicを罰することは、典型的な違法な修正第1条の報復である」と述べた。

**なぜ重要か**: この判決はAI業界と政府の関係において重要な先例となる可能性がある。AI企業が政府の圧力に対して倫理的な立場を維持できるかどうかが問われており、AIの軍事利用に関する倫理的議論に影響を与える可能性がある。また、政府がAI企業に対して不当な圧力をかけないよう、法的な保護が存在することを示している。

**関連キーワード**: AI倫理, 軍事利用, サプライチェーン・リスク, 憲法修正第1条, 政府規制
